This folder preserves the opened-source evidence notes for the 17 additional profiles appended to `data/southampton-traders-builders.csv`. Each note identifies the decision, source URLs, and the facts supporting the business's locality, activity and explicitly listed services. Rejected candidates were not added to the directory. No ratings, reviews, accreditations, credentials or missing contact details were inferred.
